# EmiVeld — artist portfolio

Website: https://hugoaudiobook.github.io/EmiVeld/ (enable GitHub Pages in Settings > Pages first).

## Update artwork without coding
1. Visit https://app.pagescms.org and log in with GitHub.
2. Install/authorize Pages CMS for the EmiVeld repository.
3. Select the EmiVeld repository.
4. Open **Artworks** to add/edit items, upload images via the media picker and fill titles and descriptions in English, Dutch and Brazilian Portuguese.
5. Save. GitHub Pages will publish the content update automatically.

Other editor sections include exhibitions, news, projects, collaborations, events, workshops, inspiration, resources and optional shop. General settings control public contact links and homepage introductions.

**Important:** This portfolio is a static site; contact uses the visitor's mail app, workshop bookings use contact links, and shop checkout is not connected. Don't publish sensitive personal information. The current gallery is empty until actual artwork is added.

## First publication
Go to repository Settings > Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.

## Files
- index.html: website shell
- assets/: theme, scripts and favicon
- content/: editable data files
- media/: uploaded art files
- .pages.yml: Pages CMS editor setup
